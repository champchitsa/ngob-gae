# งบแกะ

งบแกะเป็นต้นแบบเครื่องมือสำรวจงบประมาณที่เปลี่ยนตัวเลขเป็นคำถามสำหรับตรวจต่อ ผู้ใช้เลือกประเด็น ค้นหน่วยงาน อ่านเหตุที่ระบบจัดลำดับเคส และย้อนกลับไปยังหลักฐานต้นทางได้

[เปิดเว็บงบแกะ](https://ngob-gae.vercel.app)

## สิ่งที่ต่างจาก dashboard ทั่วไป

- แยก “ไม่มีตัวเลขในแถวข้อมูล” ออกจาก “ไม่มีการใช้จ่าย”
- แสดงสูตรคะแนนคัดกรองและข้อจำกัดของข้อมูล
- ทุกแฟ้มมีคำถาม เอกสารที่ควรขอ ฐานกฎหมาย และลิงก์ต้นทาง
- ไม่ใช้ธงความเสี่ยงเป็นข้อกล่าวหา
- ดาวน์โหลดแฟ้มที่กรองแล้วเป็น JSON ได้จากหน้าเว็บ

## ชุดข้อมูล

- PBO ผลการเบิกจ่ายงบประมาณ พ.ศ. 2568 จำนวน 241,159 แถว
- รายงานเงินกองทุนเพื่อบริหารงานสำนักงานประกันสังคม ปี 2567 ณ 31 ตุลาคม 2567
- โฟลเดอร์ OPEN Data ของงาน ซึ่งรวมงบกรุงเทพมหานคร เชียงใหม่ สมุทรปราการ PBO สปส. และเอกสารกรรมาธิการ

ไฟล์ต้นทางขนาดใหญ่ไม่ถูก commit เข้า repository นี้ สคริปต์ `scripts/analyze_pbo.py` ใช้สร้างสรุปซ้ำจากไฟล์ Excel ที่ดาวน์โหลดมาได้

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

สร้างไฟล์ production:

```bash
npm run build
```

วิเคราะห์ไฟล์ PBO ซ้ำ:

```bash
python scripts/analyze_pbo.py path/to/pbo-2568.xlsx output.json
```

## หลักการตีความ

คะแนน 100 ใช้จัดลำดับแฟ้มอ่าน โดยดูมูลค่า อัตราใช้จ่าย การโอนเปลี่ยนแปลง และความชัดเจนของข้อมูล คะแนนสูงไม่ได้แปลว่าพบทุจริต การประเมินต้องกลับไปดู TOR ราคากลาง ผู้เสนอราคา สัญญา การส่งมอบ และผลลัพธ์จริง
