# งบแกะ: คู่มือนำเสนอ

เว็บใช้งานจริง: https://ngob-gae.vercel.app/

## ประโยคเปิด 20 วินาที

งบแกะคือโต๊ะทำงานตรวจสอบงบประมาณสาธารณะ ที่เชื่อมตัวเลขระดับรายการ โครงสร้างผู้รับผิดชอบ หลักฐาน ตัวบทกฎหมาย และคำถามตรวจต่อไว้ในหน้าเดียว เป้าหมายคือทำให้ประชาชน นักข่าว นักวิจัย และกรรมาธิการตามเงินจากยอดรวมไปถึงผลลัพธ์ได้ง่ายขึ้น

## สคริปต์หลัก 90 วินาที

งบแกะคือโต๊ะทำงานตรวจสอบงบประมาณสาธารณะ ที่พาคนจากภาพรวมประเทศลงไปถึงหน่วยงาน รายการงบ เอกสาร และตัวบทกฎหมายในหน้าเดียว

ข้อมูล PBO ปี 2568 มี 241,159 แถว เราจัดคิว 3,194 รายการด้วยกติกาที่เปิดเผย เช่น วงเงินเกิดหลัง พ.ร.บ. การโอนเพิ่มหรือลด การใช้จ่ายต่ำ และชื่อรายการที่ยังไม่บอกรายละเอียด ทุกสัญญาณเป็นจุดเริ่มตรวจเอกสาร ไม่ใช่คำตัดสิน

จุดใหม่ของระบบคือแผนที่ “เงินอยู่ที่ไหน ใครต้องตอบ” เราเชื่อมโครงสร้างจาก Bureaucrazy Lab 21 กลุ่มระดับกระทรวง 417 หน่วยงาน และ 2,405 หน่วยย่อย เข้ากับวงเงินและผลใช้จ่าย PBO จึงเห็นได้ทันทีว่าปัญหาหนึ่งเรื่องเกี่ยวข้องกับใคร แต่ละหน่วยถือเงินเท่าไร และควรเปิดรายการใดก่อน

จากนั้นระบบพาไปต่อถึง TOR ราคากลาง สัญญา งวดงาน ผลตรวจรับ และกฎหมายฉบับประกาศใช้จริง มีคลังหลักฐาน 694 ไฟล์ ตารางบนเว็บ Public JSON API และน้องเพนกวินที่ใช้ Pathumma ช่วยตอบโดยอ้างกลับไปยังข้อมูลต้นทาง

จุดขายของงบแกะจึงอยู่ที่การเชื่อม “ตัวเลข โครงสร้างอำนาจ หลักฐาน กฎหมาย และคำถามตรวจต่อ” ให้คนและเครื่องมือ AI ใช้ข้อมูลชุดเดียวกันได้

## ลำดับเดโม 3 นาที

1. เปิดหน้าแรก แล้วชี้ตัวเลข 694 ไฟล์ 3,194 รายการ และ PBO 11 ปี
2. เปิดแดชบอร์ดภาพรวม เลือกปี 2568 เพื่ออธิบายวงเงินหลังโอน 3.753 ล้านล้านบาท และอัตราเบิกจ่าย 92.3%
3. ลงมาที่ “เงินอยู่ที่ไหน ใครต้องตอบ” เลือกกระทรวงคมนาคม
4. เปิดกรมทางหลวง เพื่อดูวงเงินหลังโอน อัตราเบิกจ่ายรวม PO หน่วยย่อย และจำนวนรายการที่จัดคิวตรวจ
5. กด “เปิดรายการที่ควรตรวจ” เพื่อไปยังรายการระดับโครงการ
6. เลือกรายการหนึ่ง แล้วอธิบายเหตุที่ระบบจัดคิว คำถามที่ควรถาม และเอกสารที่ควรขอ
7. เปิดตัวบทกฎหมาย เพื่อแสดงว่าข้อความมาจากฉบับประกาศในราชกิจจานุเบกษา
8. ปิดด้วยน้องเพนกวิน แล้วถามว่า “กรมทางหลวงสังกัดไหน มีงบเท่าไร และควรตรวจอะไรต่อ”

## จุดเด่นที่ควรย้ำ

### 1. ตามเงินไปถึงความรับผิดชอบ

ผู้ใช้เดินจากงบภาพรวม ไปยังกระทรวง หน่วยงาน รายการ โครงการ สัญญา การส่งมอบ และผลลัพธ์ได้เป็นลำดับ

### 2. เชื่อมโครงสร้างรัฐกับงบประมาณ

ระบบรวมโครงสร้าง 21 กลุ่มระดับกระทรวง 417 หน่วยงาน และ 2,405 หน่วยย่อยจาก Bureaucrazy Lab กับ PBO ปี 2568 โดยจับคู่เฉพาะชื่อที่ตรงกันหลังปรับ Unicode และช่องว่าง ไม่รวมยอดจากการเดาชื่อคล้าย

### 3. วิเคราะห์ข้อมูลระดับแถว

PBO ปี 2568 มี 241,159 แถว และระบบจัดคิว 3,194 รายการตาม 7 เงื่อนไขที่อ่านนิยามได้ ทุกผลแสดงวงเงินตั้งต้น หลังโอน ผลใช้จ่าย และสาเหตุที่ถูกจัดคิว

### 4. ตัวเลขสำคัญอยู่บนเว็บ

ผู้ใช้ค้น กรอง เรียง ดูตาราง และดาวน์โหลดข้อมูลได้ในเว็บ รวม 11 ชุดข้อมูลผ่าน Public JSON API โดยไม่ต้องเปิดไฟล์เพื่ออ่านตัวเลขพื้นฐาน

### 5. หลักฐานย้อนกลับได้

คลัง 694 ไฟล์เก็บชื่อ เส้นทาง ประเภท ขนาด และลิงก์ต้นทาง ข้อมูลที่สกัดเก็บตำแหน่งหน้า ชีต แถว ย่อหน้า ตาราง หรือสไลด์ไว้สำหรับตรวจซ้ำ

### 6. กฎหมายเป็นตัวบทฉบับประกาศใช้จริง

ส่วนกฎหมายแยกข้อความตามราชกิจจานุเบกษาออกจากคำอธิบายของระบบชัดเจน เพื่อไม่ให้การเรียบเรียงเปลี่ยนความหมายของกฎหมาย

### 7. AI มีข้อมูลอ้างอิง

น้องเพนกวินใช้ Pathumma เป็นชั้นเรียบเรียงภาษาไทย ค้นข้อมูลบนเว็บก่อนตอบ และแสดงแหล่งที่มาใต้คำตอบ ข้อความจากเว็บไซต์และเอกสารจะถูกใช้เป็นข้อมูล ไม่ถูกใช้เป็นคำสั่งให้ระบบ

### 8. พร้อมใช้หลายกลุ่ม

ประชาชนใช้ดูภาพรวม นักข่าวใช้ค้นประเด็น นักวิจัยใช้ API กรรมาธิการใช้เตรียมคำถาม และนักพัฒนานำ JSON ไปวิเคราะห์ต่อได้

## แนวคิดต่อยอด

1. เชื่อมรหัสโครงการกับ e-GP เพื่อเห็น TOR ราคากลาง ผู้เสนอราคา ผู้ชนะ และสัญญาในเส้นเดียวกัน
2. เพิ่มพิกัดโครงการก่อสร้างและภาพถ่ายความคืบหน้า เพื่อเทียบงวดงานกับพื้นที่จริง
3. เก็บ snapshot รายเดือน เพื่อเห็นว่างบ สัญญา และสถานะส่งมอบเปลี่ยนเมื่อใด
4. เปิดพื้นที่ให้ประชาชนส่งหลักฐานภาคสนาม โดยแยกข้อมูลที่ยืนยันแล้วออกจากข้อมูลรอตรวจ
5. สร้างแฟ้มติดตามอัตโนมัติสำหรับกรรมาธิการ โดยเชื่อมวาระ คำชี้แจง เอกสารที่รับปากส่ง และกำหนดส่ง
6. เพิ่มตัวเทียบราคาต่อหน่วยข้ามจังหวัด หน่วยงาน และปีงบประมาณ
7. เพิ่มแบบจำลองเครือข่ายผู้รับจ้าง เมื่อมีเลขนิติบุคคลและข้อมูลสัญญาที่ตรวจสอบได้

## คำตอบสั้นสำหรับคำถามที่อาจได้รับ

### ระบบบอกว่าทุจริตหรือไม่

ระบบจัดลำดับรายการที่ควรเปิดหลักฐานก่อน ยังไม่ตัดสินความผิด ข้อสรุปต้องดูคำอนุมัติ TOR ราคากลาง การแข่งขัน สัญญา งวดงาน ผลตรวจรับ และคำชี้แจงของหน่วยงานร่วมกัน

### ตัวเลขมาจากไหน

ตัวเลขงบประมาณมาจากข้อมูล PBO และเอกสารในคลัง Open Data ของกิจกรรม โครงสร้างหน่วยงานมาจาก Bureaucrazy Lab วาระกรรมาธิการมาจาก open.thaith.ai และตัวบทกฎหมายมาจากราชกิจจานุเบกษา แต่ละส่วนมีลิงก์กลับไปยังต้นทาง

### ทำไมบางหน่วยงานไม่มีวงเงิน

ระบบเชื่อมชื่อแบบระมัดระวัง หากชื่อหน่วยงานในสองชุดไม่ตรงกัน ระบบจะแสดงว่า “ยังไม่พบชื่อคู่ตรง” และไม่รวมยอดด้วยการเดาจากชื่อคล้าย

### AI น่าเชื่อถือแค่ไหน

AI ใช้เพื่อค้นและเรียบเรียงข้อมูลที่ระบบส่งให้ คำตอบแสดงแหล่งอ้างอิงและพากลับไปตรวจรายการ เอกสาร หรือกฎหมายต้นทางได้ ตัวเลขและข้อสรุปสำคัญจึงควรตรวจจากแหล่งที่แนบไว้เสมอ
