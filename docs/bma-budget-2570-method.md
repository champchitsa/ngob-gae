# วิธีจัดทำตารางงบกรุงเทพมหานคร ปีงบประมาณ 2570

หน้า "รายการงบอยู่ตรงนี้" อ่านไฟล์ตารางในโฟลเดอร์ Drive ที่ผู้จัดกิจกรรมให้มา โดยคัดไฟล์ร่างข้อบัญญัติปี 2570 จำนวน 75 ไฟล์ แล้วแสดง 25,197 แถวที่มีจำนวนเงินอย่างน้อย 10,000 บาทและมีคำว่า "บาท" ในเซลล์ถัดไป แต่ละแถวเก็บชื่อไฟล์ ชีต ลำดับแถว ชื่อรายการ รหัสงบ (เมื่อมี) หน่วยงาน จำนวนเงิน และลิงก์ต้นฉบับไว้ตรวจสอบย้อนกลับ

ข้อมูลประกอบด้วยรายการย่อยและยอดรวมย่อยในตารางเดียวกัน จึง **ห้ามบวกทุกแถวเป็นยอดงบรวม** ตัวกรอง "เฉพาะรายการย่อย" ใช้รหัสงบหรือรูปแบบหัวข้อรายการในต้นฉบับเป็นเกณฑ์ และอาจจัดประเภทผิดได้เมื่อรูปแบบตารางต่างกัน ผู้ใช้เปิดตัวกรองนี้ออกเพื่อดูแถวทั้งหมดได้ ตัวกรองหัวข้อ เช่น ICT และก่อสร้าง อาศัยคำในชื่อรายการ ไม่ได้ตีความวัตถุประสงค์ทั้งหมดของโครงการ

ส่วน "ชื่อรายการที่พบในหลายหน่วยงาน" จับคู่ชื่อที่เหมือนกันหลังตัดเลขหัวข้อและปรับช่องว่าง โดยแสดงช่วงจำนวนเงินที่พบ เป็นจุดเริ่มต้นในการเทียบหน่วยนับ คุณลักษณะ และราคาต่อหน่วย ไม่ใช่ข้อสรุปว่ารายการซ้ำซ้อนหรือมีการกระทำผิด

สร้างข้อมูลซ้ำได้ด้วย `python scripts/build_bma_budget_rows.py public/data/drive-inventory.json .workdata/drive-corpus public/data/bma-budget-2570.json` หลังสกัดไฟล์ตารางด้วย `scripts/extract_drive_corpus.py` ไฟล์ JSON และ JSON.gz ที่สร้างถูกเผยแพร่กับเว็บเพื่อให้ค้นและดาวน์โหลดได้โดยไม่ต้องเปิดไฟล์ต้นฉบับทีละไฟล์

ส่วนค้นเพิ่มจาก PDF อ่านเอกสารร่างข้อบัญญัติและเอกสารประกอบปี 2570 อีก 298 ไฟล์ รวม 31,604 หน้า แล้วทำดัชนี 101,753 บรรทัดที่มีคำภาษาไทยและตัวเลขหลักพันขึ้นไป ข้อมูลแต่ละบรรทัดระบุไฟล์ หน้า ลำดับบรรทัด วิธีอ่าน (ข้อความฝังหรือ OCR) และลิงก์ต้นฉบับ ข้อความใน PDF อาจเป็นหัวตาราง ยอดรวม หรือรายการย่อย และ OCR อาจอ่านตัวเลขผิด จึงแสดงเป็น "ตัวเลขในบรรทัด" แยกจากจำนวนเงินในแถวตาราง ห้ามนำไปบวกกับยอดจากไฟล์ตาราง สร้างใหม่ได้ด้วย `python scripts/build_bma_pdf_lines.py public/data/drive-inventory.json .workdata/drive-corpus-pdf public/data/bma-budget-2570.json public/data/bma-pdf-lines-2570.json`
